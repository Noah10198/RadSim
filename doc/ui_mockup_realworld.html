设计要点（联动版）：
1. 点选即刷新：点击左侧任意逻辑体 → 右侧 quantity / 直方图两栏刷新为该逻辑体的专属配置；未配置时显示空态引导。
2. 配置持久化：每逻辑体独立存储——切换走再点回来，配置不丢失；删空该逻辑体全部 quantity 和直方图，勾选自动消失。
3. 勾选联动：左侧 ☑ 不是手动勾选，而是由配置驱动（有任一 quantity 或直方图即打勾），无需"全选/全不选"。
4. 确认 ≠ 运行：右下角「确认」只保存配置并关闭弹窗；「▶ 运行」在主界面工具栏。弹窗全程不触发模拟。
5. filter 交互：点 quantity 行右侧 filter 标签（"+ filter" / "✓ gamma"）→ 该行下方行内展开编辑区；不是再弹子窗。
6. 单位锁定：quantity 单位（默认单位列）与直方图 x 轴单位（x 轴列）均只读、由类型一一对应，不可修改；关联量切换时 x 轴单位自动跟换。
7. 生成规则：每个已配置逻辑体生成一个 /score/create/realWorldLogVol <LV> mesh，各带自己的 quantity + /analysis/h1/create + /score/fill1D。
