设计要点（内嵌 3D 实时编辑版）：
1. 与 probe 同构、无直方图：boxMesh 不支持 fill1D，右侧只有"网格定义 + Quantity"两区。
2. 三种定位模式：「包围全部几何体（不含世界容器）」→ 除 world 外所有体积的联合 AABB；「包围选中几何」→ 该逻辑体（多实例取联合）AABB；两者 half/translate 自动算出（灰色只读）；「手动指定」→ 完全手填。模式切换即 3D 刷新。
3. nBin 实时看密度：改任一 nBin，3D 细分线立刻变化；底部实时显示体素总数 = nx·ny·nz，超阈值给性能提示（>1e6 黄 / >5e6 红）。
4. quantity 17 种全开放：含 flatSurface*（仅 boxMesh 可用）；每 quantity 行可挂 filter（紧跟 target）；单位锁定。
5. 输出不同：每个 quantity 单独 /score/dumpQuantityToFile <mesh> <qty> <out>_<qty>.csv（体素场），不是汇总 CSV。
6. 3D 与 probe 一样：表单驱动 + 旋转/缩放查看；将来可扩展网格框拖拽（编辑型），首版统一表单输入。
7. 生成 mac：/score/create/boxMesh M1 + boxSize + nBin +（translate）+ quantity/filter 行 + close；cylinderMesh 列为后续扩展。
