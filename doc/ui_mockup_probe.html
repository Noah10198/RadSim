设计要点（内嵌 3D 编辑版）：
1. 一直可视化：3D 场景内嵌在弹窗里，不是 preview 后弹窗——探针位置/大小与几何的关系随时可见。
2. 表单输入 + 3D 查看：坐标/尺寸在右侧表单输入，3D 实时刷新显示探针与几何的位置关系；3D 只做旋转/缩放，不做编辑。
3. 与 voxel 同构：voxel 是"网格框 + nBin"，probe 是"探针盒 + 拖拽定位"，同一套内嵌 3D 编辑框架。
4. 添加即所见：点「+ 添加探针」→ 场景中心出现默认 5cm 探针并自动选中，在右侧输入坐标定位到目标位置。
5. 联动规则同 realworld：点选探针 → 右侧刷新其专属 quantity/直方图；☑=已配置自动联动；单位锁定；filter 行内展开。
6. 一个探针一个位置：多位置 = 添加多个探针（每个独立 mesh），fill1D 与 CSV 按探针一一对应。
7. 材料 = 覆盖探针处材料供剂量计算，默认 G4_WATER，可选 none 关闭覆盖。
8. 生成 mac：每个探针一个 /score/create/probe <名> <半尺寸> cm 块 + material + locate + 自己的 quantity/直方图。
